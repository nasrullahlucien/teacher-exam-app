# 📚 คลังข้อสอบครูผู้ช่วย (Question Bank Structure)

โฟลเดอร์นี้รวบรวมข้อสอบทั้งหมดของแอป โดยจัดระเบียบแยกตาม **วิชา > หมวดหมู่ > หัวข้อเนื้อหา** เพื่อง่ายต่อการเปิดเข้ามาดู แก้ไข และเพิ่มข้อสอบใหม่

---

## 🗂️ โครงสร้างโฟลเดอร์

```text
public/data/questions/
├── manifest.json              # รายชื่อไฟล์ข้อสอบทั้งหมด (สร้างอัตโนมัติ)
├── kb-major/                  # 🔬 วิชาเอก (วิทยาศาสตร์/ทั่วไป)
│   ├── 1-ฟิสิกส์/              # 11 หัวข้อ (ตามสารบัญวิชาเอก)
│   ├── 2-เคมี/                 # 10 หัวข้อ
│   ├── 3-ชีววิทยา/             # 8 หัวข้อ
│   └── 4-โลก-ดาราศาสตร์-และอวกาศ/ # 8 หัวข้อ
├── ka-analysis/               # ภาค ก: การคิดวิเคราะห์ (3 ไฟล์)
├── ka-english/                # ภาค ก: ภาษาอังกฤษ (3 ไฟล์)
├── ka-civil/                  # ภาค ก: ข้าราชการที่ดี (3 ไฟล์)
├── kb-teaching/               # ภาค ข: การจัดการเรียนการสอน (3 ไฟล์)
├── kb-law/                    # ภาค ข: กฎหมายการศึกษา (3 ไฟล์)
├── kb-reform/                 # ภาค ข: แนวทางการปฏิรูปการศึกษา (2 ไฟล์)
└── kb-general/                # ภาค ข: ความรอบรู้ทั่วไป (2 ไฟล์)
```

---

## ✍️ วิธีเพิ่มข้อสอบใหม่

1. **เลือกไฟล์หัวข้อที่ต้องการเพิ่ม** เช่น ต้องการเพิ่มข้อสอบฟิสิกส์เรื่องแรง:
   เปิดไฟล์ `kb-major/1-ฟิสิกส์/02-แรงในชีวิตประจำวัน.json`

2. **ใส่ข้อสอบในรูปแบบ JSON Array** ตัวอย่างโครงสร้าง:
```json
[
  {
    "id": "kb-major-phy-016",
    "subject": "kb-major",
    "discipline": "⚡ ฟิสิกส์",
    "topic": "2. แรงในชีวิตประจำวัน (แรงลัพธ์, แรงเสียดทาน...)",
    "question": "ข้อใดเป็นแรงที่เกิดขึ้นเมื่อผิววัตถุสองชิ้นสัมผัสและพยายามเคลื่อนที่ผ่านกัน?",
    "choices": [
      "แรงเสียดทาน",
      "แรงโน้มถ่วง",
      "แรงแม่เหล็ก",
      "แรงดันอากาศ"
    ],
    "answer": 0,
    "explanation": "แรงเสียดทาน (Friction force) คือแรงที่ต้านการเคลื่อนที่ของวัตถุ เกิดขึ้นบริเวณผิวสัมผัส",
    "source": "คลังข้อสอบครูผู้ช่วย 2569"
  }
]
```

### คำอธิบายฟิลด์ข้อมูล:
| ฟิลด์ | ประเภท | คำอธิบาย |
|---|---|---|
| `id` | `string` | รหัสประจำข้อ (ห้ามซ้ำกัน เช่น `kb-major-phy-001`, `ka-law-015`) |
| `subject` | `string` | รหัสวิชา (เช่น `kb-major`, `ka-analysis`, `ka-civil`, `kb-law` เป็นต้น) |
| `discipline` | `string` *(เฉพาะวิชาเอก)* | หมวดหมู่วิชาเอก เช่น `⚡ ฟิสิกส์`, `🧪 เคมี`, `🧬 ชีววิทยา`, `🪐 โลก ดาราศาสตร์ และอวกาศ` |
| `topic` | `string` | ชื่อหัวข้อตามสารบัญ |
| `question` | `string` | ข้อความโจทย์ข้อสอบ |
| `choices` | `string[]` | ตัวเลือก 4 ข้อ (`ก`, `ข`, `ค`, `ง`) |
| `answer` | `number` | ดัชนีเฉลย (0 = ก, 1 = ข, 2 = ค, 3 = ง) |
| `explanation` | `string` | คำอธิบายเฉลยอย่างละเอียด |
| `source` | `string` | ที่มาของข้อสอบ |

---

## 🔄 คำสั่งตรวจสอบและรวมไฟล์ (Sync)

หลังจากแก้ไขหรือเพิ่มไฟล์ข้อสอบใหม่ สามารถพิมพ์คำสั่ง:

```bash
npm run sync-questions
```

ระบบจะ:
1. ตรวจสอบ syntax ของไฟล์ JSON ทุกไฟล์ว่าถูกต้องหรือไม่
2. อัปเดต `manifest.json` ให้อัตโนมัติ
3. รวมไฟล์ข้อสอบเข้ากับ `<subject-id>.json` เพื่อความเร็วสูงสุด
